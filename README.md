# RainDown

一个简洁的个人网站初稿，包含博客、学习笔记与天气记录，可作为 GitHub Pages 静态站点使用。

## 本地查看

直接打开 `index.html` 即可浏览；也可在项目目录启动本地服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8000 。无需安装前端依赖或执行构建。

## 文件结构

- `index.html`：首页。
- `blog.html`、`posts/`：博客列表和文章。
- `notes.html`、`notes/`：笔记列表和正文。
- `weather.html`：天气记录示例、趋势图与表格。
- `assets/css/style.css`：全站样式。
- `assets/js/main.js`：左侧索引开关、手机端抽屉和笔记主题筛选。
- `assets/js/theme.js`：全站深浅色切换与主题记忆。
- `assets/css/home-rain.css`、`assets/js/home-rain.js`：首页宣纸背景、细雨与涟漪。
- `assets/images/paper-reference.png`：首页使用的纸纹参考图。
- `assets/favicon.svg`：站点图标。
- `CHANGELOG.md`：简短编辑日志。

## 内容与字体

当前文章、笔记、日期和天气均为示例内容。天气数据为虚构数据，没有接入实时天气服务。图表与表格使用同一组数据。

样式优先调用本机已安装的方正博雅宋简体（`FZBoYaSongS-GB`），其次调用方正博雅宋 GBK，再回退到设备上的宋体。项目不附带字体文件；访客未安装相应字体时会显示后备字体。若需让所有访客显示同一字体，后续可配置具有相应网页使用授权的字体文件。

## 数学公式

博客与笔记正文已接入 KaTeX 0.19.0，自动渲染 `.prose` 内的公式。脚本、样式及公式字体均保存在 `assets/vendor/katex-0.19.0/`，无需联网加载，也无需安装浏览器插件；目录内附 MIT 许可证。

- 行内公式写作 `$E=mc^2$` 或 `\(E=mc^2\)`。
- 独立公式写作 `$$\lim_{x\to 0}\frac{\sin x}{x}=1$$` 或 `\[...\]`。
- `pre`、`code` 中的示例不会渲染；其他需保留原样的内容可加 `class="no-math"`。
- HTML 中公式的小于号和与号仍需写为 `&lt;`、`&amp;`；LaTeX 命令使用单个反斜杠，如 `\varepsilon`，不要按 JavaScript 字符串写成双反斜杠。
- 新建正文页时，复制现有正文页中 KaTeX 的样式与脚本引用；独立公式过长时可横向滚动。

## 后续维护

博客与笔记列表、正文均有左侧索引，当前页面会高亮；桌面端可收起并记住开关状态，手机端默认收起，点击后以抽屉展开，可用关闭按钮、遮罩或 Esc 关闭。

索引展开和收起使用约 250 毫秒的平滑动画，桌面端正文宽度同步变化，手机端抽屉与遮罩同步过渡；站内页面切换采用短暂淡入淡出，保留同页锚点和新窗口打开的原有行为。系统开启“减少动态效果”时关闭这些动画。

顶部按钮可切换深浅色模式，首次访问跟随系统主题，手动选择后记住偏好；浏览器禁用本地存储时，当前页面仍可切换。

首页使用浅黄色宣纸背景、细雨涟漪与缓慢流动的云雾，背景跟随深浅主题切换；页脚可暂停全部动效，系统开启“减少动态效果”时默认静止。云雾低分辨率绘制，每秒更新 12 次。独立测试页仍保留在 `experiments/ink-rain-water/`。

文章和笔记目前为独立 HTML 页面；新增内容时同步更新对应列表与首页入口。天气记录目前为静态页面，修改时须同步更新摘要、曲线和表格。笔记分类由 `data-note-category` 标识，分类按钮可在 `notes.html` 中扩展。

新增文章或笔记时，同步更新对应列表及正文页面中 `.index-sidebar` 内的链接；博客按年份分组，笔记按学科分组，并为当前页索引链接设置 `aria-current="page"`。

确认页面效果后，再将示例内容替换为真实内容。此版本仅保存在当前项目中，尚未部署。
