C 语言：循环与分支

2026.10.19编程 / C 语言示例学习笔记
初稿预览本页学习笔记与日期均为示例，供查看页面效果。

循环的执行顺序

for 循环先执行初始化，再判断条件；条件成立时执行循环体，随后执行更新表达式，再次判断条件。

for (int i = 0; i < 3; i++) {
    printf("%d\n", i);
}

这段代码依次输出 0、1、2。while 同样先判断条件；do ... while 则先执行一次循环体，再判断条件。

switch 与 break

switch 根据表达式的值跳到对应的 case。如果没有 break，程序会继续执行后续分支的语句，直到遇到跳转语句或离开整个 switch。

break 退出最内层的循环或 switch。因此，在循环内部的 switch 中使用 break，通常只会离开 switch。

在分支中结束外层循环

一种清晰的写法是设置结束标志，并在循环体中检查。下面是可以独立编译运行的示例；输入 0 或输入结束时，循环退出。

#include <stdio.h>

int main(void)
{
    int done = 0;
    while (!done) {
        int item;
        if (scanf("%d", &item) != 1) break;

        switch (item) {
            case 0:
                done = 1;
                break;
            default:
                printf("item = %d\n", item);
                break;
        }
    }
    return 0;
}

continue 的作用范围

continue 结束最内层循环的本次迭代。在 for 中，接着执行更新表达式；在 while 中，接着重新判断循环条件。

switch 本身不是循环。位于循环内的 switch 中若出现 continue，它作用于包围它的最内层循环。
