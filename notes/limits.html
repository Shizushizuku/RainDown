极限：从直觉到定义

2026.10.20数学 / 微积分示例学习笔记
初稿预览本页学习笔记与日期均为示例，供查看页面效果。

从接近开始

观察数列 $a_n = 1/n$：随着 n 增大，各项逐渐接近 0。这里的“接近”，不是要求某一项等于 0，而是要求此后的所有项都能落入指定的小范围。

关键不在于前面有限项的表现，而在于从某一项开始，后面的项是否持续满足要求。

数列极限的定义

设数列为 {an}。如果对于任意 ε > 0，都存在正整数 N，使得当 n > N 时，均有：

$$|a_n-A| < \varepsilon$$

就称数列 {an} 收敛于 A，记为 an → A。

对于 1/n → 0，给定 ε > 0，可取一个大于 1/ε 的正整数 N。当 n > N 时，便有 1/n < ε。

几个基本性质

  • 唯一性：一个收敛数列只有一个极限。
  • 有界性：收敛数列一定有界，但有界数列不一定收敛，例如 (−1)n。
  • 运算法则：若 an → A，bn → B，则和、差、积的极限分别为 A + B、A − B、AB；商的法则还要求 B ≠ 0，且分母在所讨论的项上有定义。

留给自己的问题

  1. “任意 ε”与“存在 N”的顺序为什么不能交换？
  2. 为什么只改变数列的有限项，不会改变它的极限？
  3. 怎样用定义证明极限的唯一性？
